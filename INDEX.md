## Naming Convention

Topic folders use the naming convention `{topic-slug}_{StartMonth}{Year}-{EndMonth}{Year}/`.
Single-month research uses `{topic-slug}_{Month}{Year}/`.
Planned topics (no tests yet) have no timespan suffix until testing begins.
Re-testing a topic creates a NEW folder with the new timespan.
